# Manufacturing Defect Detection

A computer vision project for industrial quality inspection.

## Objectives
- Detect surface defects using object detection.
- Identify structural and logical anomalies.
- Evaluate models using reproducible experiments.

## Datasets
- MVTec LOCO AD
- NEU-DET

## Planned Models
- PatchCore for anomaly detection.
- YOLO11n for surface defect detection.
